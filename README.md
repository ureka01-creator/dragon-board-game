# DRAGON BOARD — Web Prototype V0.4.6

## V0.4.6 핵심 변경

### 파티 편성
- 같은 칸의 READY 영웅끼리 2~4명 파티 편성 가능.
- 파티 편성/변경/해산은 주사위를 굴리기 전에만 가능.
- 파티는 D6 1개로 함께 이동하고, 이동/칸 행동 후 파티원 전원의 월드 턴이 종료.
- 전투에는 편성된 파티원만 전원 참가.
- SOLO 영웅은 같은 칸에 다른 영웅이 있어도 자동 전투 참가하지 않음.
- 전투 중 쓰러진 영웅은 파티에서 자동 이탈하고 마을로 귀환.

### 전리품 소유권
- 장비/소비 아이템은 공용 가방이 아니라 영웅별 개인 가방에 보관.
- 전투를 시작한 영웅(파티라면 파티 리더)이 전리품 획득자.
- 장비 획득 직후에는 획득 영웅이 바로 장착하거나 자기 가방에 보관만 가능.
- 다른 직업에게 즉시 장착하는 기능 삭제.
- 골드는 현재 프로토에서 파티 공용 유지.

### 아이템 전달
- 자신의 월드 턴, 주사위를 굴리기 전에 사용.
- 같은 칸에 있는 다른 영웅에게 아이템 1개 전달 가능.
- 가방 아이템과 장착 중 장비 모두 전달 가능. 장착 중 장비는 자동 해제되어 상대 가방으로 이동.
- 전달을 실행하면 이번 월드 턴 즉시 종료.
- 파티 상태에서는 파티가 하나의 월드 유닛이므로 전달 시 파티 전체 월드 턴 종료.

### 캐릭터 상태창
- `PERSONAL BAG` 추가.
- 현재 행동 중인 SOLO 또는 파티 구성원은 주사위 전에 개인 가방 장비를 장착 가능.
- 장비 교체 시 기존 장비는 같은 영웅의 개인 가방으로 이동.
