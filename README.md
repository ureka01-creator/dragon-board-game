# DRAGON BOARD — Web Prototype V0.6.3.8

1~4명의 영웅이 월드를 탐험하고 장비와 아이템을 모아 네 지역의 보스를 쓰러뜨린 뒤, 봉인석 4개로 드래곤의 성을 열어 고대 드래곤을 처치하는 협동 다크 판타지 보드 RPG 프로토타입.

## 현재 상태

- 현재 배포 버전: **V0.6.3.8**
- 기본 브랜치: `main`
- 배포: GitHub Pages
- 파티 시스템은 현재 잠금 상태이며 영웅들은 SOLO 월드 턴으로 행동
- 현재 집중 테스트: **월드 이동 종료 규칙 / 막다른 길 / 도착 타일 이벤트 / 드래곤의 성 진행**

## 핵심 게임 흐름

1. 1~4명의 영웅 선택
2. 영웅별 랜덤 지역 마을에서 시작
3. D6을 굴려 월드 이동
4. 전투·사건·보물·상점·휴식·소형 던전으로 성장
5. 네 지역 보스를 각각 처음 토벌해 봉인석 4개 획득
6. 봉인석 4/4 달성 시 드래곤의 성 출현
7. 최종 던전 4단계 돌파
   - 성문 수호자
   - 봉인의 회랑
   - 용의 제단
   - 고대 드래곤
8. 고대 드래곤 처치 시 VICTORY

## V0.6.3.8

- 회복이 필요한 상태로 마을을 `지나간다` 선택한 뒤 전진 경로가 0개면 막다른 길로 정상 확정
- 지역 입구에서 `지나간다` 또는 지역 이동 후 전진 경로가 0개면 남은 MOVE 소멸 후 정상 턴 종료
- 특별 타일 분기 뒤에도 공통 `continueOrFinalizeStoppedMovement()`를 거쳐 외길 자동 진행 / 갈림길 대기 / 막다른 길 확정을 일관되게 처리
- Chromium 모바일 + WebKit iPhone 회귀 테스트를 GitHub Actions에 추가

## V0.6.3.7

### 이동 종료 규칙

- D6 결과만큼 한 칸씩 이동하며 MOVE를 즉시 차감
- 선택 가능한 길이 하나뿐인 외길은 자동으로 계속 이동
- 실제 갈림길에서는 자동 이동을 멈추고 플레이어 선택 대기
- 한 번의 이동 중 이미 지나간 칸은 다시 방문할 수 없음
- 이동력이 남아 있어도 더 이상 진행할 수 없는 막다른 길이면 즉시 정지
- 막다른 길에서 남은 MOVE는 전부 소멸
- 막다른 길 도착 후 해당 칸을 최종 도착칸으로 처리하여 타일 공개 및 콘텐츠 실행
- 사건·전투·보물·상점 등 도착 타일의 실제 이벤트가 MOVE 소멸 처리 때문에 누락되지 않도록 흐름 정리

### 지역 입구 / 마을

- 지역 입구 도착 시 `이동한다 / 지나간다` 선택
- 이동 후 MOVE가 남아 있으면 새 지역에서도 이동 계속
- 회복이 필요한 상태로 마을을 지나갈 때는 `들러서 회복 / 지나간다` 선택
- 마을에 들러 회복하면 남은 MOVE를 포기하고 해당 월드 턴 종료

### 버전 / 캐시

- DEV 실행 `dev-bootstrap.js?v=0637`

## 월드 이동 규칙

- 월드 턴 순서는 선택한 영웅의 고정 순서로 진행
- 이동 중 경유 칸은 최종 도착칸이 아니면 콘텐츠가 발동하지 않음
- 처음 최종 도착한 미탐험 칸만 타일을 공개
- 막다른 길은 남은 MOVE와 관계없이 최종 도착으로 취급
- 새 D6을 굴리면 해당 이동의 방문 경로 기록 초기화
- 지역 입구를 통과해도 MOVE가 남아 있으면 계속 이동 가능

## 전투 / 아이템

- D20 기반 전투
- 기사 / 궁수 / 마법사 / 도적 각각 고유 패시브와 스킬 보유
- 개인 가방 최대 3칸
- 직업별 장비 제한 적용
- 전투 소비 아이템과 필드 회복 아이템 지원
- 일반 전투칸 재방문 시 아무 일 없음 / 일반 몬스터 / 정예 몬스터 / 작은 발견 중 랜덤 결과
- 지역 보스는 한 번 토벌하면 다시 생성되지 않음

## 봉인석 / 드래곤의 성

- NORMAL 모드에서는 별도 THREAT 게이지를 사용하지 않음
- A/B/C/D 네 지역 보스가 각각 봉인석 1개 보유
- 각 지역 보스를 처음 토벌할 때 봉인석 획득
- 봉인석 4/4 즉시 드래곤의 성 출현
- 드래곤 성 최종 던전 진행 단계는 재도전 시 유지
- 고대 드래곤 보스전에서는 연막탄 도주 불가

## DEV 모드

URL에 `?dev=1`을 붙이면 개발자 테스트 런타임을 사용한다.

주요 테스트 기능:

- 영웅 HP 조정 / 완전 회복 / 즉사
- 아이템 지급 / 가방 비우기
- 골드 지급
- 지역 보스 강제 처치
- 드래곤의 성 즉시 개방
- 지역 마을 순간 이동
- 드래곤의 성 테스트 진입
- 다음 D6 결과 강제 지정
- 현재 전투 적 HP 1 설정

DEV 모드는 테스트 편의를 위한 기능이며 일반 플레이에서는 사용하지 않는다.
