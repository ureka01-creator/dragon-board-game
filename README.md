# DRAGON BOARD — Web Prototype V0.4.7

## V0.4.7 핵심 변경

### 파티 시스템 잠금
- `PARTY_SYSTEM_ENABLED = false`.
- 파티 편성 UI 숨김.
- 모든 영웅은 SOLO로 이동/전투.
- 같은 칸에 다른 영웅이 있어도 전투에 자동 참가하지 않음.
- 파티 코드는 삭제하지 않고 비활성 상태로 유지.

### 아이템 전달 룰 유지
- 전리품은 획득한 영웅의 개인 소유.
- 자신의 월드 턴, 주사위를 굴리기 전에 같은 칸의 다른 영웅에게 아이템 1개 전달 가능.
- 아이템을 전달하면 해당 영웅의 이번 턴이 즉시 종료.

### 4개 지역 월드맵
- 월드는 A / B / C / D 네 지역으로 확장.
- 네 지역 모두 동일한 7x7 타일 토폴로지 사용.
- 각 지역은 인접 지역 입구로 연결:
  - A ↔ B
  - A ↔ C
  - B ↔ D
  - C ↔ D
- 모바일에서 타일이 너무 작아지지 않도록 한 번에 한 지역 보드를 크게 표시.
- 상단 2x2 WORLD REGIONS 미니맵에서 A/B/C/D를 확인 가능.
- 영웅이 지역 입구에 도착하면 인접 지역으로 이동하고 해당 보드로 화면 전환.

### 새 게임마다 랜덤 생성
- 게임 시작마다 4개 지역의 테마 배치가 다시 섞임.
- 묘지 / 숲 / 전쟁터 / 화산 테마가 A~D에 랜덤 배치.
- 동일한 타일 구조를 유지하면서 전투/보물/사건/휴식/상점/위험/보스 타일 위치를 매 판 다시 섞음.
- 각 지역 안의 타일 이름도 중복 없이 구성.

### 드래곤의 성 출현 규칙 변경
- 게임 시작 시 드래곤의 성은 맵에 존재하지 않음.
- 아래 둘 중 하나를 만족하면 월드의 유효 타일 하나가 랜덤으로 `🐉 드래곤의 성`으로 변함.
  1. 봉인석 3개 획득
  2. DRAGON THREAT 12 도달
- 출현 지역은 A/B/C/D 중 랜덤.
- WORLD REGIONS 미니맵에 `🐉` 표시.
- 기존 `THREAT 9 강제 개방` 삭제.
- 기존 `THREAT 12 즉시 GAME OVER`는 현재 프로토타입에서 비활성화. THREAT는 12에서 멈추고 드래곤 성 출현 트리거로 사용.
- 최종 드래곤 성/패배 규칙은 이후 설계.
