# DRAGON BOARD — Web Prototype V0.4.9

## V0.4.9 핵심 변경

- 새 게임을 시작할 때 **각 영웅의 시작 지역이 랜덤**으로 정해진다.
  - A/B/C/D 네 지역 중 하나를 각 영웅마다 독립적으로 랜덤 선택한다.
  - 시작 칸은 선택된 지역의 **정중앙 마을**이다.
  - 따라서 여러 영웅이 같은 지역에서 시작할 수도 있다.
- A/B/C/D 모든 지역의 중앙 칸을 **마을**로 통일했다.
- 영웅이 쓰러지면 **쓰러졌던 지역을 기억**한다.
  - 즉시 해당 지역 중앙 마을 위치로 귀환 처리된다.
  - 다음 라운드에 그 지역 마을에서 HP/마나를 회복하고 부활한다.
  - 더 이상 무조건 A 지역 왕국 마을로 돌아가지 않는다.
- 게임 시작 시 화면도 첫 번째 행동 영웅이 실제로 시작한 지역을 보여준다.
- 기존 고정 월드 턴 순서 유지: 기사 → 궁수 → 마법사 → 도적.
- 파티 시스템은 계속 잠금 상태.

## 기존 핵심 기능 유지

- A/B/C/D 4지역 랜덤 월드 생성
- 지역별 동일한 7×7 토폴로지 + 매 게임 다른 내부 타일 배치
- 봉인석 3개 또는 THREAT 12에서 용의 성 랜덤 출현
- D6 월드 이동 및 점프 토큰 애니메이션
- D20 전투 / 전투 애니메이션 / 전투 로그
- 개인 전리품 및 장비 Paper Doll
- 아이템 전달 시 월드 턴 종료
- 캐릭터 상태창
