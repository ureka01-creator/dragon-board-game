# DRAGON BOARD — Web Prototype V0.5.4.1

## V0.5.4.1
- 새 게임마다 5개 후보 중 봉인 목표 3개를 랜덤 선택한다.
- 가능한 목표: 지역 보스 1회, 전투 3회 승리, 보물 2개 개봉, 이벤트 2개 해결, 지역 경계 2회 통과.
- 목표 하나 완료 시 봉인석 1개 획득. 기존 지역 보스 자동 봉인석 지급은 제거했다.
- 영웅 패널의 `🗿 0/3` 자원 요약을 누르면 이번 게임 봉인 목표와 진행도를 확인할 수 있다.
- 봉인석 3개 또는 THREAT 12에서 용의 성 출현 규칙은 유지한다.


## V0.5.3.1
- 월드 보드 상단 턴 표시는 영웅 이름만 표시한다. 예: `🛡 기사 턴`.
- `주사위를 굴려 이동`, `1~N칸 이동 가능` 안내 문구를 제거했다. 이동 가능한 칸은 보드 하이라이트로만 안내한다.


## V0.5.3.1
- 전투 중 현재 플레이어를 둘러싸던 노란색 사각 프레임 제거. 캐릭터 자체 글로우만 유지.
- 월드 보드 제목을 고정 문구 대신 현재 지역의 월드 이름(예: 피의 전쟁터, 망자의 땅 등)으로 표시.

## V0.5.3.1 Hotfix
- 인게임 진입 시 `.board-panel.scrollIntoView()` 강제 스크롤을 제거했다.
- 화면 전환 직후 문서 최상단을 한 번만 고정해 iOS Safari에서 화면이 가운데로 점프하거나 재정렬되는 현상을 줄였다.
- 이후 턴 전환/맵 전환에서는 사용자 스크롤 위치를 임의로 바꾸지 않는다.

## V0.5.3.1 Hotfix
- 전투 중 `🎒 아이템`을 눌러도 창이 보이지 않던 문제 수정. 전투 오버레이보다 아이템 모달 z-index를 높였다.
- 소비 아이템이 없을 때도 버튼을 눌러 `사용 가능한 소비 아이템이 없음` 안내를 확인할 수 있다.
- 전투 아이템 모달은 닫기/전투 종료 시 상태를 확실히 초기화한다.


## V0.5.3.1 Hotfix

- 가방에서 장비 장착 시 즉시 교체하지 않고 `현재 장비 ↔ 새 장비` 비교창을 먼저 표시.
- 전리품으로 장비를 얻었을 때도 현재 같은 슬롯 장비와 새 장비를 나란히 비교 표시.
- 기존 장비가 없으면 `장비 없음`으로 명확히 표시.
- 화면/캐시/README/ZIP 버전 V0.5.3.1 동기화.

## V0.5.2.2 Hotfix

- 월드 이동 주사위가 사건/결과 모달 위에 남아 보이던 문제 수정.
- 목적지 이동이 끝나는 순간 이동 주사위를 정리하고, 주사위 레이어도 모달보다 아래로 조정.

- 이벤트 선택 결과가 모험 기록에만 남고 화면에 보이지 않던 문제 수정.
- 검은 고양이처럼 선택 후 골드/HP/MANA/THREAT가 변하는 사건은 `EVENT RESULT` 결과창을 표시.
- 결과창에서 실제 변화량(예: `💰 골드 +5`)을 확인한 뒤 계속 진행.
- 전리품/전투 이벤트는 기존 전용 화면을 그대로 사용해 중복 결과창을 띄우지 않음.
- 화면/캐시/README/ZIP 버전 V0.5.2.2 동기화.

## V0.5.2 핵심 변경

- `이동 안 함` 제거
  - D6을 굴린 뒤 반드시 1칸 이상 이동
  - 이동 가능 범위는 `1 ~ D6 결과`
- 보물칸 1회성 처리
  - 처음 도착한 영웅이 보상을 획득하면 해당 칸은 `📭 빈 상자`로 변경
  - 같은 게임에서 다시 파밍할 수 없음
- 정식 프로토 아이템 카드 30장
  - 무기 8
  - 방어구 7
  - 장신구 7
  - 소비 아이템 8
- 개인 가방 최대 3칸
- 전리품은 획득한 영웅 소유
- 다른 영웅에게 전달하려면 같은 칸에서 `아이템 전달` 사용 → 전달한 영웅의 월드 턴 종료
- 직업별 장착 제한 적용
  - 장착할 수 없는 장비도 개인 가방에 보관/전달 가능
- 장비 효과 실제 적용
  - 화염검: 언데드 추가 피해 / 트롤 재생 차단
  - 마도 지팡이: 마법사 기본 마력탄 D8
  - 용살검: 정예·보스 추가 피해
  - 레인저 망토: 첫 적 공격 명중 감소
  - 별빛 로브·마나 수정: 최대 MANA 증가
  - 용비늘 갑옷: 화염 피해 감소
  - 행운의 반지: 전리품 2장 중 1장 선택
  - 수호의 부적: 첫 피해 감소
  - 매의 눈: 첫 공격 명중 증가
  - 피의 펜던트: 직접 처치 시 회복
  - 여행자의 장화: 이동 D6 1 → 2
  - 운명의 동전: Natural 1 전투당 1회 재굴림
- 전투 소비 아이템 버튼 추가
  - 회복약 / 마나 물약 / 화염병 / 폭탄 / 연막탄 / 집중의 비약
  - 불사조의 깃털은 HP 0 시 자동 사용
  - 소비 아이템은 전투 라운드당 1개, 사용 후에도 공격 가능
- 파티 기능은 계속 잠금 상태 (`PARTY_SYSTEM_ENABLED = false`)
