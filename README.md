# DRAGON BOARD — Web Prototype V0.5.0

## V0.5.0 핵심 변경

- `이동 안 함` 제거
  - D6을 굴린 뒤 반드시 1칸 이상 이동
  - 이동 가능 범위는 `1 ~ D6 결과`
- 보물칸 1회성 처리
  - 처음 도착한 영웅이 보상을 획득하면 해당 칸은 `📭 빈 상자`로 변경
  - 같은 게임에서 다시 파밍할 수 없음
- 정식 프로토 아이템 카드 30장
  - 무기 8
  - 방어구 7
  - 장신구 7
  - 소비 아이템 8
- 개인 가방 최대 3칸
- 전리품은 획득한 영웅 소유
- 다른 영웅에게 전달하려면 같은 칸에서 `아이템 전달` 사용 → 전달한 영웅의 월드 턴 종료
- 직업별 장착 제한 적용
  - 장착할 수 없는 장비도 개인 가방에 보관/전달 가능
- 장비 효과 실제 적용
  - 화염검: 언데드 추가 피해 / 트롤 재생 차단
  - 마도 지팡이: 마법사 기본 마력탄 D8
  - 용살검: 정예·보스 추가 피해
  - 레인저 망토: 첫 적 공격 명중 감소
  - 별빛 로브·마나 수정: 최대 MANA 증가
  - 용비늘 갑옷: 화염 피해 감소
  - 행운의 반지: 전리품 2장 중 1장 선택
  - 수호의 부적: 첫 피해 감소
  - 매의 눈: 첫 공격 명중 증가
  - 피의 펜던트: 직접 처치 시 회복
  - 여행자의 장화: 이동 D6 1 → 2
  - 운명의 동전: Natural 1 전투당 1회 재굴림
- 전투 소비 아이템 버튼 추가
  - 회복약 / 마나 물약 / 화염병 / 폭탄 / 연막탄 / 집중의 비약
  - 불사조의 깃털은 HP 0 시 자동 사용
  - 소비 아이템은 전투 라운드당 1개, 사용 후에도 공격 가능
- 파티 기능은 계속 잠금 상태 (`PARTY_SYSTEM_ENABLED = false`)

## 유지되는 규칙

- 월드 턴 순서 고정: 기사 → 궁수 → 마법사 → 도적
- 각 영웅 시작 지역은 A/B/C/D 중앙 마을 중 랜덤
- 사망 시 죽었던 지역의 중앙 마을로 귀환, 다음 라운드 부활
- 4개 확장 지역은 매 게임 타일 내용 랜덤
- 봉인석 3개 또는 THREAT 12에서 용의 성 랜덤 출현
