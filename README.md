## V0.6.3.7

### 이동 종료 규칙

- D6 결과만큼 한 칸씩 이동하며 MOVE를 즉시 차감
- 선택 가능한 길이 하나뿐인 외길은 자동으로 계속 이동
- 실제 갈림길에서는 자동 이동을 멈추고 플레이어 선택 대기
- 한 번의 이동 중 이미 지나간 칸은 다시 방문할 수 없음
- 이동력이 남아 있어도 더 이상 진행할 수 없는 막다른 길이면 즉시 정지
- 막다른 길에서 남은 MOVE는 전부 소멸
- 막다른 길 도착 후 해당 칸을 최종 도착칸으로 처리하여 타일 공개 및 콘텐츠 실행
- 사건·전투·보물·상점 등 도착 타일의 실제 이벤트가 MOVE 소멸 처리 때문에 누락되지 않도록 흐름 정리

### 지역 입구 / 마을

- 지역 입구 도착 시 `이동한다 / 지나간다` 선택
- 이동 후 MOVE가 남아 있으면 새 지역에서도 이동 계속
- 회복이 필요한 상태로 마을을 지나갈 때는 `들러서 회복 / 지나간다` 선택
- 마을에 들러 회복하면 남은 MOVE를 포기하고 해당 월드 턴 종료

### 버전 / 캐시

- 타이틀 표시를 `PROTOTYPE V0.6.3.7`로 동기화
- 일반 실행 `game.js?v=0637`
- DEV 실행 `dev-bootstrap.js?v=0637`

## 월드 이동 규칙

- 월드 턴 순서는 선택한 영웅의 고정 순서로 진행
- 이동 중 경유 칸은 최종 도착칸이 아니면 콘텐츠가 발동하지 않음
- 처음 최종 도착한 미탐험 칸만 타일을 공개
- 막다른 길은 남은 MOVE와 관계없이 최종 도착으로 취급
- 새 D6을 굴리면 해당 이동의 방문 경로 기록 초기화
- 지역 입구를 통과해도 MOVE가 남아 있으면 계속 이동 가능

- A/B/C/D 네 지역 보스가 각각 봉인석 1개 보유
- 각 지역 보스를 처음 토벌할 때 봉인석 획득

- 고대 드래곤 보스전에서는 연막탄 도주 불가
