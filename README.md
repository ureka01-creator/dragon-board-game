# DRAGON BOARD — Web Prototype V0.1

1~4인 협력형 다크 판타지 보드 RPG의 첫 웹 프로토타입입니다.

## 현재 구현
- 영웅 1~4명 선택
- 기사 / 궁수 / 마법사 / 도적 기본 스탯
- 라운드 및 자유 행동 순서
- D6 이동
- 나온 수 이하 거리의 노드 선택 이동
- 이동하지 않기
- 분기형 월드맵
- 라운드 종료 시 DRAGON THREAT +1
- 위협도 9 강제 개방 조건 표시
- 위협도 12 게임오버
- 봉인석 3개 구조의 초기 연결
- 모바일 Safari 대응 레이아웃
- 레트로 픽셀풍 임시 UI
