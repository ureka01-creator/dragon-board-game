# DRAGON BOARD — Web Prototype V0.5.7.0


## V0.5.7.0
- 영웅 4명의 전투 개성 1차 정리 및 SOLO 전투 호환 보강
- 기사 패시브를 `철벽`으로 변경: 전투 라운드마다 처음 받는 피해 2 감소
- 도적 `급소 공격`을 파티 의존 조건에서 제거하고, 이미 피해를 입은 적에게 라운드당 1회 +D6 피해로 변경
- 궁수의 Natural 19~20 크리티컬, 마법사의 MANA/마력 폭발 규칙은 유지
- 영웅 선택 화면에 패시브와 고유기를 함께 표시


## V0.5.6.7
- 남은 MOVE가 있어도 막다른 길에 도착하면 이동을 즉시 종료하도록 유지
- 막다른 길 안내 모달이 도착칸의 사건/전투/상점 모달과 충돌하던 문제 수정
- 막다른 길에서는 남은 MOVE 소멸을 로그로만 표시하고 해당 칸의 실제 이벤트를 즉시 실행


## V0.5.6.6
- 주사위 마지막 또르륵 구간의 Y축 중앙 보간과 micro-bounce 제거
- 주사위는 바닥 높이에서 굴림을 완전히 끝낸 뒤 결과 면을 확정
- 확정된 주사위만 짧은 직선 이동으로 맵 중앙에 배치한 뒤 결과 확대
- `굴림 → 확정 → 중앙 이동 → 결과 강조` 순서를 명확하게 분리

## V0.5.6.5
- 주사위 확정 직전 별도의 280ms 중앙 이동을 제거

- 최종 착지 회전을 360도 정렬로 부드럽게 수렴시켜 결과 확대 시작 시 위치/각도 점프 제거

## V0.5.6.4

## V0.5.6.3
- 한 번의 주사위 이동 중 같은 칸 재방문 금지
- A→B→A 같은 즉시 왕복 및 A→B→C→D→B 같은 루프 이동 방지
- 이미 이번 이동에서 지나간 칸은 다음 이동 후보에서 제외
- 미방문 방향이 하나도 없고 이동력이 남아 있으면 막다른 길로 판정해 즉시 정지
- 막다른 길에서는 남은 이동력 소멸, 최종 칸만 공개/효과 발동
- 새 주사위를 굴리면 방문 경로 기록 초기화
